# Icons Placeholder

This directory contains application icons for different platforms:

- `icon.png` - Linux icon (256x256 PNG)
- `icon.ico` - Windows icon (multiple sizes in ICO format)
- `icon.icns` - macOS icon (ICNS format)

For now, you can use any 256x256 PNG image as a placeholder icon.
The build process will use these icons when creating platform-specific executables.
